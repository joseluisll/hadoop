# artifacts also get) and the shaded client jars. It fails on every
# breaking, implementor, jpms or jre finding no rule here matches.

# Format: <kind> <regex>  # <ticket>: <why>; announced: <where users are told>
# Both regexes match the whole kind and subject. Subjects:
#   <old jar> -> <new jar>|<class>[#<member>]   or  <jar>|<class>[#<member>]
#   <old jar> -> <new jar>                      (jar-module-name-changed,
#                                                jar-class-version-raised)
# with jars relative to the distribution. Say where the impact is announced
# ("announced: HADOOP-19970 release note"); a rule without it, or with
# "announced: no", shows in the report as an impact nobody was told about.
